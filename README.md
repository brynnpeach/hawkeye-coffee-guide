# Hawkeye Coffee Guide

A static, multi-page fictional coffee-shop guide for the MKTG:4400 class project at the University of Iowa.

## Pages
- `index.html` — homepage
- `breakfast.html` — fictional coffee shops with breakfast
- `study-spots.html` — fictional study-space comparison
- `about.html` — project and fiction disclosure
- `styles.css` — responsive styling
- `robots.txt` and `sitemap.xml` — starter crawl/discovery files

## Publish on GitHub Pages
1. Sign in to GitHub and create a **public** repository (for example, `hawkeye-coffee-guide`).
2. Upload all files in this folder to the repository's root (not inside another nested folder).
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select branch **main** and folder **/(root)**, then save.
6. Wait for GitHub Pages to publish and open the URL it provides.
7. Replace `YOUR-USERNAME` and `YOUR-REPOSITORY` in the canonical links, `robots.txt`, and `sitemap.xml` with your actual GitHub username and repository name. Commit the changes.
8. Test every page and navigation link in a private/incognito window to confirm no login is required.
